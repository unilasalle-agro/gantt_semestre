Gantt de semestre

Déposez le planning du semestre (Excel ou CSV). Le Gantt regroupe les modules par UE et fait ressortir les examens et les remises de rapports. Le fichier reste dans votre navigateur et n’est envoyé nulle part.

Déposer un fichier .xlsx ou .csv ici, ou cliquer pour le choisir Colonnes attendues : Date, Début, Fin, Durée en minutes, Type d’activité, Module, UE

Chaque colonne est un jour, chaque trait un jour de cours. Survolez un jour pour voir les horaires. « Créneaux » compte les lignes du fichier, groupes parallèles inclus. Les chiffres sous l’axe des mois sont les lundis.

Ajouter une remise de rapport

Les remises ajoutées ici sont mémorisées dans ce navigateur, sur cet ordinateur. Pour les conserver ou les partager, téléchargez le planning mis à jour : elles y figurent sur des lignes de type REMISE, que l’application relit au prochain dépôt.
